# Interação Humana com o PC

Graphical Calculator
Project developed in Java using JavaFX to implement a graphical calculator with a clean and interactive user interface.  

**Features:**  
- Perform basic arithmetic operations (addition, subtraction, multiplication, division)  
- Support for parentheses and operator precedence  
- Error handling for invalid expressions (e.g., division by zero)  
- Responsive and intuitive graphical interface built with JavaFX
